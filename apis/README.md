# 🗞️ Bujumbura Post

Plateforme d'actualités full-stack — React + Tailwind (front) / Express + Sequelize + MySQL (back).

## 🚀 Installation

### Backend
\`\`\`bash
cd server
npm install
# Configurer .env (MySQL)
npm run seed        # données de test
npm run dev
\`\`\`

### Frontend
\`\`\`bash
cd client
npm install
npm run dev
\`\`\`
